## 👋 About Me

Hi! I'm **Arman Sheikh**, an aspiring Frontend Developer from **Karachi, Pakistan**.

I'm learning **Modern Web App Development at SMIT** and improving my skills by building practical projects. I enjoy turning ideas into responsive, useful web applications and learning how real products work — from frontend interfaces to authentication, databases and deployment.

My current focus is:

- Building responsive interfaces with **React**.
- Improving my JavaScript and TypeScript fundamentals.
- Working with **Supabase** and **Firebase** for backend services.
- Creating practical applications such as dashboards, productivity tools and e-commerce projects.
- Understanding the code I write, debugging issues and improving project quality.
- Improving my English and technical communication.

**My long-term goal:** Become a professional Software Engineer and work with an international team in a remote role.

> I believe in learning by building. My repositories show my progress, experiments and practical work. I keep learning and improving one project at a time.
